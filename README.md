# 🐾 PetCare2

A comprehensive all-in-one platform for pet owners — built to make caring for pets easier, from vet visits to lost-pet alerts and everything in between.

## 📱 About

PetCare2 is a mobile application that brings together everything a pet owner needs in one place: veterinary appointments, vaccination reminders, a pet-lover community, an in-app store, and a lost & found system for missing pets.

## ✨ Key Features

- 🩺 **Vet Appointment Booking** — Schedule and manage appointments with veterinarians directly from the app.
- 💉 **Vaccination Reminders** — Never miss a vaccine dose with smart, automated reminders.
- 🐶 **Pet Breed Explorer** — Browse different animal species and breeds, with photos and information to learn about them.
- 📸 **Photo Uploads** — Upload and save photos of your pets.
- 🚨 **Lost & Found** — Report a lost pet or help reunite found pets with their owners through community alerts.
- 👥 **Pet Owner Community** — Connect, share experiences, and interact with other pet owners.
- 🛒 **Pet Store** — Browse and purchase pet medications and supplies within the app.

## 🛠️ Tech Stack

**Frontend (Mobile App)**
- [Flutter](https://flutter.dev) — Cross-platform mobile app development (Dart)

**Backend**
- [Node.js](https://nodejs.org) — Server-side runtime and REST API
- [MongoDB](https://www.mongodb.com) — NoSQL database for storing users, pets, appointments, and listings

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) installed
- Node.js and MongoDB set up for the backend (separate repository/server)

### Run the app
```bash
git clone https://github.com/iy156/petcare2.git
cd petcare2
flutter pub get
flutter run
```
